# Loguin

Static site for Loguin — data infrastructure installation (CCTV, networks, access control, AV, IT) across the UK.

## Run locally

Open [index.html](index.html) directly in a browser, or serve it:

```bash
python3 -m http.server 8080
```

## Run in Docker

```bash
docker compose up --build
```

Then visit http://localhost:8091.
